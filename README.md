# PC Temperature Monitor

Portable Windows application written in C# / .NET 8 for monitoring CPU, GPU and motherboard temperatures.

## Features
- CPU temperature
- GPU temperature
- Motherboard temperature
- Configurable warning and critical thresholds
- Windows toast notifications and sound alerts
- System tray support
- Optional start with Windows
- Self-contained `win-x64` portable build

## Build
Run `build-portable.ps1` on Windows with .NET 8 SDK installed, or use the GitHub Actions workflow to build the portable artifact automatically.
